# Шпаргалка

## Где что лежит на Linux-сервере
| Что ищу | Где |
|---|---|
| Настройки системы и программ | `/etc` (например, `/etc/nginx/`) |
| Логи | `/var/log` (например, `/var/log/nginx/`) |
| Файлы сайтов | `/var/www` |
| Установленные программы | `/usr` (`/usr/bin`, `/usr/sbin`) |
| Домашние папки пользователей | `/home/имя` |
| Папка администратора root | `/root` |
| Временные файлы | `/tmp` |
| Информация о системе «прямо сейчас» | `/proc` (виртуальная) |
| Диск C: Windows (из WSL) | `/mnt/c` |

## Навигация
| Команда | Что делает | Пример |
|---|---|---|
| `pwd` | показать, где я сейчас | `pwd` |
| `cd путь` | перейти в папку | `cd /var/log` |
| `cd ..` | на уровень выше | `cd ..` |
| `cd ~` или `cd` | домой (`/home/vetal`) | `cd ~` |
| `cd -` | вернуться в предыдущую папку | `cd -` |
| `ls` | список файлов | `ls` |
| `ls -l` | подробный список (права, владелец, размер) | `ls -l /etc` |
| `ls -a` | показать скрытые файлы (с точкой в начале) | `ls -a ~` |
| `ls -lah` | всё сразу, размеры понятные (K, M, G) | `ls -lah` |
| `ls -lhS` | сортировка по размеру, большие сверху | `ls -lhS /var/log` |
| `ls -ld папка` | права самой папки, а не содержимого | `ls -ld /root` |
| `tree` | структура папок деревом | `tree` |

Обозначения: `.` — текущая папка, `..` — родительская, `~` — домашняя, `/` — корень.

## Просмотр файлов
| Команда | Что делает | Пример |
|---|---|---|
| `cat файл` | вывести весь файл | `cat /etc/os-release` |
| `head -n 3 файл` | первые 3 строки | `head -n 3 /proc/meminfo` |

## Справка
| Команда | Что делает |
|---|---|
| `man команда` | полное руководство (`/слово` — поиск, `n` — следующее совпадение, `q` — выход) |
| `команда --help` | краткая справка |

## Информация о системе
| Команда | Что показывает |
|---|---|
| `whoami` | под каким пользователем я работаю |
| `cat /etc/os-release` | версия Linux |
| `uname -r` | версия ядра |
| `free -h` | память |
| `df -h` | место на дисках |
| `cat /proc/uptime` | сколько секунд работает система |

## Права администратора
| Команда | Что делает |
|---|---|
| `sudo команда` | выполнить ОДНУ команду от root |

Приглашение: `$` — обычный пользователь, `#` — root (осторожно!)

## Пакеты (apt)
| Команда | Что делает |
|---|---|
| `sudo apt update` | обновить СПИСОК пакетов (ничего не ставит) |
| `sudo apt upgrade` | установить обновления (читать список перед `Y`!) |
| `sudo apt install пакет` | установить программу |

## Git
| Команда | Что делает |
|---|---|
| `git status` | что изменилось (смотреть ВСЕГДА перед `add`) |
| `git add .` | подготовить все изменения к коммиту |
| `git commit -m "Add ..."` | сохранить изменения в истории |
| `git push` | отправить на GitHub |
| `git log --oneline` | история коммитов кратко |
| `git remote -v` | куда отправляется репозиторий |
| `git config --global --list` | мои настройки Git |

Цикл: изменил → `Ctrl+S` → `git status` → `git add .` → `git commit -m "..."` → `git push`
`ahead of 'origin/main' by N commits` — есть локальные коммиты, которые ещё не на GitHub → нужен `git push`

## SSH
| Команда | Что делает |
|---|---|
| `ssh-keygen -t ed25519 -C "метка"` | создать пару ключей |
| `cat ~/.ssh/id_ed25519.pub` | показать ПУБЛИЧНЫЙ ключ (только `.pub`!) |
| `ssh -T git@github.com` | проверить доступ к GitHub |

## WSL (в PowerShell Windows)
| Команда | Что делает |
|---|---|
| `wsl --list --verbose` | список дистрибутивов и версия WSL |

## VS Code
| Действие | Как |
|---|---|
| Открыть папку из терминала | `code .` |
| Сохранить | `Ctrl+S` (белая точка ● на вкладке = не сохранено) |
| Предпросмотр Markdown | `Ctrl+Shift+V` |
| Буквы у файлов | `M` — изменён, `U` — новый, Git о нём не знает |

## Работа с файлами
| Команда | Что делает | Пример |
|---|---|---|
| `mkdir папка` | создать папку | `mkdir backup` |
| `mkdir -p a/b/c` | создать вложенные папки | `mkdir -p ~/sandbox/project` |
| `touch файл` | создать пустой файл | `touch log/a.log` |
| `cp файл копия` | скопировать файл | `cp app.conf app.conf.bak` |
| `cp -r папка копия` | скопировать папку целиком | `cp -r config config_old` |
| `mv старое новое` | переименовать | `mv logs log` |
| `mv файл папка/` | переместить | `mv a.log backup/` |
| `rm файл` | удалить НАВСЕГДА (корзины нет) | `rm a.log` |
| `rm -i файл` | удалить с подтверждением (Enter = нет) | `rm -i b.log` |
| `rm -r папка` | удалить папку со всем содержимым | `rm -r log` |
| `rmdir папка` | удалить ПУСТУЮ папку (безопаснее) | `rmdir log` |

Перед правкой конфига: `cp файл файл.bak`
Перед удалением: `pwd` и `ls` — где я и что удаляю
