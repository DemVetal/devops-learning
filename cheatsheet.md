# Шпаргалка

## Где что лежит на Linux-сервере
| Что ищу | Где | Аналог в Windows |
|---|---|---|
| Установленные программы | `/usr` (`/usr/bin`, `/usr/sbin`) | `C:\Program Files` |
| Настройки программ | `/etc` (например, `/etc/nginx/`) | «Настройки» программ |
| Файлы сайтов | `/var/www` | «Мои документы» — мои данные |
| Логи | `/var/log` (например, `/var/log/nginx/`) | Журнал событий |
| Домашние папки пользователей | `/home/имя` | `C:\Users\имя` |
| Папка администратора root | `/root` | папка администратора |
| Временные файлы | `/tmp` | `C:\Windows\Temp` |
| Информация о системе «прямо сейчас» | `/proc` (виртуальная) | Диспетчер задач |
| Диск C: Windows (из WSL) | `/mnt/c` | — |
| Пользователи (логин, UID, домашняя папка, оболочка) | `/etc/passwd` | — |
| Хэши паролей (только root) | `/etc/shadow` | — |
| Группы и их участники | `/etc/group` | — |
| Шаблон домашней папки нового пользователя | `/etc/skel` | — |
| Лог входов и использования sudo | `/var/log/auth.log` | Журнал безопасности |
| Данные, которые обслуживает сервер | `/srv` | — |

Программа — в `/usr`, её настройки — в `/etc`, сайт, который она показывает, — в `/var/www`, её логи — в `/var/log`.

## Навигация
| Команда | Что делает | Пример |
|---|---|---|
| `pwd` | показать, где я сейчас | `pwd` |
| `cd путь` | перейти в папку | `cd /var/log` |
| `cd ..` | на уровень выше | `cd ..` |
| `cd ~` или `cd` | домой (`/home/vetal`) | `cd ~` |
| `cd -` | вернуться в предыдущую папку | `cd -` |
| `ls` | список файлов | `ls` |
| `ls -l` | подробный список (права, владелец, размер) | `ls -l /etc` |
| `ls -a` | показать скрытые файлы (с точкой в начале) | `ls -a ~` |
| `ls -lah` | всё сразу, размеры понятные (K, M, G) | `ls -lah` |
| `ls -lhS` | сортировка по размеру, большие сверху | `ls -lhS /var/log` |
| `ls -ld папка` | права самой папки, а не содержимого | `ls -ld /root` |
| `tree` | структура папок деревом | `tree` |

Обозначения: `.` — текущая папка, `..` — родительская, `~` — домашняя, `/` — корень.

## Поиск файлов
Шаблон: `find ГДЕ_ИСКАТЬ УСЛОВИЕ`

| Пример | Что найдёт |
|---|---|
| `find ~/devops-learning -name "*.md"` | все файлы `.md` в репозитории |
| `find /etc -name "*.conf"` | все файлы, оканчивающиеся на `.conf` |
| `find ~ -name "app.conf"` | файл с точным именем |
| `find ~ -type f -name "*.log"` | только файлы (`f` — file) |
| `find ~ -type d -name "notes"` | только папки (`d` — directory) |
| `find /var/log -size +100k` | файлы больше 100 КБ |
| `find / -size +100M` | файлы больше 100 МБ (когда кончается место) |
| `sudo find /etc -name "*.key"` | поиск и в закрытых папках |

- `*` — любые символы; шаблон со звёздочкой ВСЕГДА в кавычках: `"*.conf"`
- Размеры: `k` — маленькая, `M` и `G` — большие (`+100K` — ошибка!)
- find заходит и в скрытые папки → указывать место поиска как можно точнее
- `Permission denied` в find — не авария: find сообщает и продолжает искать
- `ls` смотрит в одну папку, `find` — во все вложенные

## Пользователи и группы
| Команда | Что делает |
|---|---|
| `whoami` | моё имя |
| `id` | мой UID, GID и группы (текущей сессии) |
| `id имя` | UID, GID и группы пользователя (актуальные данные) |
| `groups` | список моих групп |
| `sudo adduser имя` | создать пользователя (папка, пароль — всё сразу) |
| `su - имя` | войти под другим пользователем (нужен ЕГО пароль) |
| `exit` | вернуться обратно |
| `sudo deluser --remove-home имя` | удалить пользователя и его папку |
| `sudo groupadd имя` | создать группу |
| `sudo groupdel имя` | удалить группу |
| `sudo usermod -aG группа имя` | добавить пользователя в группу |

- ВСЕГДА `-aG`! Без `-a` пользователь потеряет все остальные группы (и `sudo`)
- Новые группы применяются только после нового входа (`su - имя` или перезайти по SSH)
- Строка `/etc/passwd`: `логин:x:UID:GID:комментарий:домашняя_папка:оболочка`
- Строка `/etc/group`: `имя:x:GID:участники`
- UID 0 — root; UID < 1000 — служебные; UID ≥ 1000 — люди
- `/usr/sbin/nologin` — войти под этим пользователем нельзя (служебный)

## Права доступа
Строка прав: `-rwxr-xr--` = тип + владелец (u) + группа (g) + остальные (o)

| Буква | Файл | Папка |
|---|---|---|
| `r` (4) | читать | видеть список имён |
| `w` (2) | изменять | создавать, удалять, переименовывать файлы внутри |
| `x` (1) | запускать | входить (`cd`) |

Разбор `Permission denied`:
1. `ls -l файл` / `ls -ld папка` — владелец, группа, права
2. `id` — кто я, мои группы
3. Моя тройка: владелец? → 1-я; в группе файла? → 2-я; иначе → 3-я (срабатывает ОДНА)
4. Есть ли нужная буква в моей тройке?
5. Проверить папку: `x` — войти, `w` — создать/удалить

| Число | Буквы | Где |
|---|---|---|
| `644` | `rw-r--r--` | обычные файлы, конфиги |
| `600` | `rw-------` | секреты, приватные ключи |
| `755` | `rwxr-xr-x` | папки, скрипты, программы |
| `700` | `rwx------` | личные папки (`~/.ssh`) |
| `770` | `rwxrwx---` | общая папка группы |

| Команда | Что делает |
|---|---|
| `chmod u+x файл` | владельцу добавить запуск |
| `chmod o-r файл` | остальным убрать чтение |
| `chmod 600 файл` | установить права цифрами |
| `chmod -R 755 папка` | рекурсивно (осторожно!) |
| `sudo chown владелец:группа файл` | сменить владельца и группу |
| `sudo chown -R www-data:www-data /var/www/site` | отдать сайт веб-серверу |
| `sudo chgrp группа файл` | сменить только группу |
| `sudo chmod g+s папка` | setgid: новые файлы получат группу папки |
| `./файл` | запустить файл из текущей папки |

- Права НЕ наследуются: папка — это дверь, у каждого файла свои права
- root игнорирует права
- Новые файлы по умолчанию читаются всеми → секреты сразу `chmod 600`
- НИКОГДА `chmod 777`
- `t` (sticky bit, на `/tmp`) — удалять можно только свои файлы
- `s` в тройке группы — setgid
- Первая строка скрипта: `#!/bin/bash` (shebang)
- Каждый `sudo` записывается в `/var/log/auth.log`
- Пустой вывод команды = успех («молчание — знак успеха»)

## Потоки и перенаправление
| Поток | № | Что это |
|---|---|---|
| stdin | 0 | ввод (клавиатура или файл) |
| stdout | 1 | обычный вывод |
| stderr | 2 | ошибки |

| Запись | Что делает |
|---|---|
| `команда > файл` | вывод в файл (ПЕРЕЗАПИСЫВАЕТ молча!) |
| `команда >> файл` | дописать в конец файла |
| `команда 2> файл` | ошибки в файл |
| `команда 2>/dev/null` | ошибки выбросить |
| `команда > файл 2>&1` | вывод и ошибки в один файл |

- `>` — для свежих отчётов, `>>` — для логов (накопление). Повторный `>>` дублирует данные
- `/dev/null` — «чёрная дыра»
- Команда без файла ждёт ввода с клавиатуры → `Ctrl+C`

## Конвейер и обработка текста
`команда1 | команда2` — вывод левой становится вводом правой (передаётся только stdout, НЕ файл)

| Команда | Что делает |
|---|---|
| `grep "текст" файл` | строки, где есть текст |
| `grep -i` | без учёта регистра |
| `grep -v` | строки, где текста НЕТ |
| `grep -c` | количество строк |
| `grep -n` | с номерами строк |
| `grep -r "текст" папка` | искать во всех файлах папки |
| `cut -d ':' -f 7 файл` | вырезать 7-ю колонку, разделитель `:` |
| `sort` / `sort -n` / `sort -nr` | по алфавиту / как числа / от большего |
| `uniq` / `uniq -c` | склеить СОСЕДНИЕ повторы / и посчитать (нужен `sort` перед ним!) |
| `awk '{print $1}' файл` | 1-я колонка (разделитель — пробелы, любое количество) |
| `awk '{print $1, $7}'` | несколько колонок |
| `awk '{print $NF}'` | последняя колонка |
| `awk -F ':' '{print $7}'` | другой разделитель |
| `awk '$9 == 404' файл` | строки по условию |
| `awk '$9 == 500 {print $7}' файл` | условие + колонка |
| `printf "a\nb\n" > файл` | записать несколько строк (`\n` — новая строка) |

**Рецепт «топ самых частых»:**
`... | sort | uniq -c | sort -nr | head`

**Примеры:**
- топ IP: `awk '{print $1}' access.log | sort | uniq -c | sort -nr | head`
- топ кодов ответа: `awk '{print $9}' access.log | sort | uniq -c | sort -nr`
- страницы с ошибкой 500: `awk '$9 == 500 {print $7}' access.log | sort | uniq -c | sort -nr`
- число конфигов: `find /etc -name "*.conf" 2>/dev/null | wc -l`
- Числа — БЕЗ кавычек (`$2 > 30`), текст — В кавычках (`$3 == "Киев"`). `"30"` в кавычках = сравнение как текст (по символам, как в словаре) — ошибка на числах
- Сравнение — `==` (один `=` — это присваивание)
- Запятая в `print` сама ставит пробел: `print $1, "получает", $4`
- `$0` — вся строка, `$NF` — последнее поле
- Условия: `==`, `!=`, `>`, `>=`, `<`, `<=`; «и» — `&&`
- Пример: имена людей (без nobody): `awk -F ':' '$3 >= 1000 && $3 < 65534 {print $1}' /etc/passwd`
- Огромный вывод → сначала `| head`.

## Лог веб-сервера (Nginx/Apache)
`IP - - [дата] "МЕТОД /страница HTTP/1.1" КОД РАЗМЕР "откуда" "программа"`
- `$1` — IP, `$4` — время, `$7` — страница, `$9` — код ответа, `$10` — размер
- Коды: `200` — успех, `301` — переадресация, `404` — не найдено, `500` — ошибка сервера
- access.log — ЧТО произошло; error.log — ПОЧЕМУ сломалось
