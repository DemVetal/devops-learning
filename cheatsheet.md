# Шпаргалка

## Где что лежит на Linux-сервере
| Что ищу | Где | Аналог в Windows |
|---|---|---|
| Установленные программы | `/usr` (`/usr/bin`, `/usr/sbin`) | `C:\Program Files` |
| Настройки программ | `/etc` (например, `/etc/nginx/`) | «Настройки» программ |
| Файлы сайтов | `/var/www` | «Мои документы» — мои данные |
| Логи | `/var/log` (например, `/var/log/nginx/`) | Журнал событий |
| Домашние папки пользователей | `/home/имя` | `C:\Users\имя` |
| Папка администратора root | `/root` | папка администратора |
| Временные файлы | `/tmp` | `C:\Windows\Temp` |
| Информация о системе «прямо сейчас» | `/proc` (виртуальная) | Диспетчер задач |
| Диск C: Windows (из WSL) | `/mnt/c` | — |

Программа — в `/usr`, её настройки — в `/etc`, сайт, который она показывает, — в `/var/www`, её логи — в `/var/log`.

## Навигация
| Команда | Что делает | Пример |
|---|---|---|
| `pwd` | показать, где я сейчас | `pwd` |
| `cd путь` | перейти в папку | `cd /var/log` |
| `cd ..` | на уровень выше | `cd ..` |
| `cd ~` или `cd` | домой (`/home/vetal`) | `cd ~` |
| `cd -` | вернуться в предыдущую папку | `cd -` |
| `ls` | список файлов | `ls` |
| `ls -l` | подробный список (права, владелец, размер) | `ls -l /etc` |
| `ls -a` | показать скрытые файлы (с точкой в начале) | `ls -a ~` |
| `ls -lah` | всё сразу, размеры понятные (K, M, G) | `ls -lah` |
| `ls -lhS` | сортировка по размеру, большие сверху | `ls -lhS /var/log` |
| `ls -ld папка` | права самой папки, а не содержимого | `ls -ld /root` |
| `tree` | структура папок деревом | `tree` |

Обозначения: `.` — текущая папка, `..` — родительская, `~` — домашняя, `/` — корень.

## Git
| Команда | Что делает |
|---|---|
| `git status` | что изменилось (смотреть ВСЕГДА перед `add`) |
| `git add .` | подготовить все изменения к коммиту |
| `git commit -m "Add ..."` | сохранить изменения в истории |
| `git push` | отправить на GitHub |
| `git log --oneline` | история коммитов кратко |
| `git remote -v` | куда отправляется репозиторий |
| `git config --global --list` | мои настройки Git |

Цикл: изменил → `Ctrl+S` → `git status` → `git add .` → `git commit -m "..."` → `git push`
`ahead of 'origin/main' by N commits` — есть локальные коммиты, которые ещё не на GitHub → нужен `git push`

## Работа с файлами
| Команда | Что делает | Пример |
|---|---|---|
| `mkdir папка` | создать папку | `mkdir backup` |
| `mkdir -p a/b/c` | создать вложенные папки | `mkdir -p ~/sandbox/project` |
| `touch файл` | создать пустой файл | `touch log/a.log` |
| `cp файл копия` | скопировать файл | `cp app.conf app.conf.bak` |
| `cp -r папка копия` | скопировать папку целиком | `cp -r config config_old` |
| `mv старое новое` | переименовать | `mv logs log` |
| `mv файл папка/` | переместить | `mv a.log backup/` |
| `rm файл` | удалить НАВСЕГДА (корзины нет) | `rm a.log` |
| `rm -i файл` | удалить с подтверждением (Enter = нет) | `rm -i b.log` |
| `rm -r папка` | удалить папку со всем содержимым | `rm -r log` |
| `rmdir папка` | удалить ПУСТУЮ папку (безопаснее) | `rmdir log` |

Перед правкой конфига: `cp файл файл.bak`
Перед удалением: `pwd` и `ls` — где я и что удаляю

## Чтение файлов
| Команда | Что делает | Пример |
|---|---|---|
| `cat файл` | вывести весь файл (для маленьких файлов) | `cat config/app.conf` |
| `cat -n файл` | весь файл с номерами строк | `cat -n /etc/hosts` |
| `head -n 5 файл` | первые 5 строк (без `-n` — 10) | `head -n 5 /var/log/dpkg.log` |
| `tail -n 5 файл` | последние 5 строк (без `-n` — 10) | `tail -n 5 /var/log/dpkg.log` |
| `tail -f файл` | следить за логом в реальном времени, выход — `Ctrl+C` | `tail -f /var/log/nginx/error.log` |
| `less файл` | постраничный просмотр большого файла | `less /var/log/dpkg.log` |
| `wc -l файл` | сколько строк в файле | `wc -l /var/log/dpkg.log` |

### Клавиши в less (и в man — там тоже less)
| Клавиша | Действие |
|---|---|
| `Пробел` / `b` | страница вниз / вверх |
| `/слово` + `Enter` | поиск |
| `n` / `N` | следующее / предыдущее совпадение |
| `G` / `g` | в конец / в начало |
| `q` | выход |

Большой лог — не `cat`, а `less` или `tail`.
Сайт упал → `tail -n 50 error.log` → `tail -f error.log` + обновить страницу.

## Поиск файлов
Шаблон: `find ГДЕ_ИСКАТЬ УСЛОВИЕ`

| Пример | Что найдёт |
|---|---|
| `find ~/devops-learning -name "*.md"` | все файлы `.md` в репозитории |
| `find /etc -name "*.conf"` | все файлы, оканчивающиеся на `.conf` |
| `find ~ -name "app.conf"` | файл с точным именем |
| `find ~ -type f -name "*.log"` | только файлы (`f` — file) |
| `find ~ -type d -name "notes"` | только папки (`d` — directory) |
| `find /var/log -size +100k` | файлы больше 100 КБ |
| `find / -size +100M` | файлы больше 100 МБ (когда кончается место) |
| `sudo find /etc -name "*.key"` | поиск и в закрытых папках |

- `*` — любые символы; шаблон со звёздочкой ВСЕГДА в кавычках: `"*.conf"`
- Размеры: `k` — маленькая, `M` и `G` — большие (`+100K` — ошибка!)
- find заходит и в скрытые папки → указывать место поиска как можно точнее
- `Permission denied` в find — не авария: find сообщает и продолжает искать
- `ls` смотрит в одну папку, `find` — во все вложенные
