# Словарь

| Термин | English | Суть |
|---|---|---|
| Корневой каталог | root directory | самая верхняя папка Linux, `/`, в ней лежит всё |
| Домашний каталог | home directory | моя личная папка `/home/vetal`, обозначается `~` |
| Суперпользователь | root / superuser | администратор, у которого есть все права; его папка `/root` |
| Текущий каталог | current / working directory | где я сейчас, обозначается `.`, показывает `pwd` |
| Родительский каталог | parent directory | папка на уровень выше, обозначается `..` |
| Абсолютный путь | absolute path | путь от корня, начинается с `/`: `/var/log` |
| Относительный путь | relative path | путь от текущей папки: `../tmp` |
| Стандарт иерархии ФС | FHS, Filesystem Hierarchy Standard | правила, где что лежит в Linux: `/etc`, `/var`, `/usr`... |
| Символическая ссылка | symlink / symbolic link | ярлык, который указывает на другой файл или папку (`/bin → usr/bin`) |
| Точка монтирования | mount point | папка, куда «подвешен» диск (`/mnt/c`) |
| Виртуальная файловая система | virtual filesystem | файлов нет на диске, ядро создаёт их на лету (`/proc`) |
| Ядро | kernel | главная программа Linux, управляет железом и процессами |
| Обратная совместимость | backward compatibility | старые программы продолжают работать после изменений |
| Права доступа | permissions | кто может читать, писать и запускать файл (`rwx`) |
| Владелец | owner | пользователь, которому принадлежит файл |
| Пакетный менеджер | package manager | программа для установки ПО, в Ubuntu это `apt` |
| Пакет | package | программа, подготовленная для установки через apt |
| Дистрибутив | distribution / distro | готовая сборка Linux: Ubuntu, Debian, CentOS... |
| LTS | Long Term Support | версия с долгой поддержкой, её ставят на серверы |
| Автодополнение | tab completion | Tab дописывает имя файла или команды |
| Руководство | manual / man page | встроенная документация: `man ls` |
| Репозиторий (Git) | repository | папка проекта с историей изменений |
| Коммит | commit | сохранённый «снимок» изменений с описанием |
| Область подготовки | staging area | изменения после `git add`, готовые к коммиту |
| Неотслеживаемый файл | untracked file | новый файл, о котором Git ещё не знает |
| Удалённый репозиторий | remote | копия репозитория на сервере (GitHub), обычно называется `origin` |
| Приватный ключ | private key | секретная половина SSH-пары, хранится только у меня, права 600 |
| Публичный ключ | public key | открытая половина SSH-пары (`.pub`), её кладут на GitHub или сервер |
| Отпечаток ключа | fingerprint | короткий «код» ключа сервера для проверки, что сервер настоящий |
| Двухфакторная аутентификация | 2FA, two-factor authentication | вход по паролю + коду из приложения |
| Подсистема Windows для Linux | WSL, Windows Subsystem for Linux | настоящий Linux внутри Windows |
| Рекурсивно | recursive (`-r`) | папка со всем содержимым, до самого дна |
| Резервная копия | backup | копия файла на случай, если что-то сломается |
| Песочница | sandbox | место для экспериментов, где ничего не жалко |
| Откат | rollback | возврат к рабочей версии |
| Подстановочный знак | wildcard (`*`) | «любые символы»: `*.conf` |
| Постраничный просмотрщик | pager (`less`) | показывает большой файл по экрану |
| Следить за логом | follow (`tail -f`) | показывать новые строки по мере появления |
| Триггер | trigger | действие apt после установки пакета |
| Журнал systemd | journal | главный системный лог, читается через `journalctl` |
| Образ | image | готовая заготовка системы, из которой её разворачивают |
| Идентификатор пользователя | UID, User ID | номер пользователя; система работает с номерами, а не с именами |
| Идентификатор группы | GID, Group ID | номер группы |
| Служебный пользователь | system / service account | пользователь для работы программы (www-data, syslog), UID < 1000, войти нельзя |
| Оболочка | shell | программа, принимающая команды (`/bin/bash`) |
| Основная группа | primary group | группа пользователя по умолчанию, обычно с тем же именем |
| Дополнительные группы | supplementary groups | группы, которые дают дополнительные права (sudo, adm) |
| Принцип минимальных привилегий | principle of least privilege | давать ровно столько прав, сколько нужно для работы |
| Хэш | hash | «отпечаток» пароля; из пароля получить легко, обратно — практически нельзя |
| Права доступа | permissions | кто что может делать с файлом: r, w, x |
| Владелец | owner (user, `u`) | пользователь, которому принадлежит файл |
| Группа файла | group (`g`) | группа, к которой относится файл |
| Остальные | others (`o`) | все, кто не владелец и не в группе файла |
| Липкий бит | sticky bit (`t`) | в общей папке удалять можно только свои файлы («общий холодильник») |
| Бит setgid | setgid (`s`) | новые файлы в папке получают группу папки |
| Шебанг | shebang (`#!/bin/bash`) | первая строка скрипта: какой программой его выполнять |
| Список sudo | sudoers | кому разрешено пользоваться sudo |
| Добавить | append (`-a`) | дописать к существующему, не заменяя |
| Права по умолчанию | umask | настройка, которая определяет права новых файлов |
| Приветствие при входе | MOTD, message of the day | сообщение, которое показывается при входе в систему |
| Шаблон домашней папки | skel (`/etc/skel`) | файлы, которые копируются каждому новому пользователю |
| Аудит | audit | возможность выяснить, кто, когда и что делал |
| Подстановка шаблонов | globbing | Bash раскрывает `*` в имена файлов ДО запуска команды |
| Перенаправление в конец файла | append redirect (`>>`) | дописать вывод в конец файла |
