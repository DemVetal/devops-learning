# Занятие 1. Файловая система Linux и навигация

## Главное своими словами
В Linux одно дерево каталогов и оно начинается с "/". Всё остальное монтируется (mount) в какую-то папку дерева например диск C я вижу как /mnt/c


## Где что лежит
| Каталог | Что там |
|---|---|
| `/` | Корень, Основной каталог, тут лежат все каталоги и файлы |
| `/etc` | папка в которой хранят настройки приложений 	(конфигурация системы и программ) |
| `/var/log` | изменяемый каталог который хранит логи всей системы и программ (изменяемые данные (variable)) |
| `/var/www` | здесь обычно хранится сайт |
| `/home` | родной каталог юзера не root (домашние каталоги пользователей) |
| `/root` | родной каталог папка пользователя root (домашний каталог администратора root) |
| `/usr` | Здесь хранятся все установленные программы, драйвера и разные данные (установленные программы и библиотеки) |
| `/tmp` | временные файлы. которые могут чиститься при перезагрузке |
| `/proc` | Виртуальная папка, данные в которой появляются только в момент когда к ней обратились (виртуальные: информация о процессах и ядре, на диске их нет) |
| `/mnt/c` | диск C в системе Windows  (точки монтирования) |

## Пути
- Абсолютный: начинается с "/" - cd /var/log
- Относительный: не начинается с "/" - cd ../var
- `.` — текущая папка, `..` — родительская папка (на уровень выше), `~` — моя домашняя папка /home/vetal. Это обозначения, их можно использовать в любой команде: `cd ..`, `ls ~`

## Что стало открытием
- Виртуальный каталог /proc - файлы размером 0, но с данными. Которые повляются только когда к ним обращаешься.
- Понятия абсолютного и относительных путей и как по ним перемещатся правильно
- как пользоваться правами и зачем не нужно постонно всё выполнять через root
