# Учебная среда

## Что установлено
- Windows 11 + WSL2, Ubuntu 24.04 LTS
- VS Code с расширением WSL
- Git, SSH-ключ для GitHub

## Как начать работу
- Открыть терминал Ubuntu: Пуск - Ubuntu 24.04
- Перейти в репозиторий: `cd ~/devops-learning`
- Открыть в VS Code: `code .`

## Как проверить версию WSL
- В PowerShell: `wsl --list --verbose` — в колонке Version должно быть 2

## Где лежат файлы
- Учебные файлы: `/home/vetal/devops-learning`
- Почему не на диске C: (`/mnt/c`): потому что линукс читает права по своему и можно случайно что то испортить.

## Доступ к GitHub
- Пара SSH-ключей типа ed25519:
  - приватный (private): `~/.ssh/id_ed25519` — секрет, хранится только у меня, права 600
  - публичный (public): `~/.ssh/id_ed25519.pub` — его можно отдавать, он добавлен на GitHub
