# Занятие 2. Работа с файлами: создание, копирование, чтение, поиск

## Главное своими словами
Файлы можно создавать, копировать, перемещать, удалять, читать (просматривать) и искать.


## Безопасность
- Перед правкой конфига: обязательно делаю бэкап .bak
- Перед удалением: проверяю где нахожусь
- Чем опасен rm: удаляет файл безвозвратно

## Создать / копировать / переместить / удалить
[своими словами: mkdir -p, touch, cp, cp -r, mv, rm -i, rm -r, rmdir]
- mkdir -p создаёт папку с вложениями
- touch создаёт файл
- cp копирует файл
- cp -r копирует папку и все файлы в ней
- mv перемещает файл или переименовать если в одной папке
- rm -i удаляет файл только с подтверждением
- rm -r рекурсивно удаляет папку и все файлы и папки в ней
- rmdir удаляет только пустую папку

## Читать
- маленький файл: cat выводит весь файл, cat -n с номерами строк
- начало / конец файла: head -n первый строки / tail -n последние строки
- лог в реальном времени: tail -f лог в реальном времени
- большой лог с поиском: less вывод всего лога постранично

## Искать
- find: 
find ~ -name "app.conf"	файл с точным именем app.conf в домашней папке
find /etc -name "*.conf"	все файлы, имя которых заканчивается на .conf
find ~ -type d -name "notes"	только папки (d — directory) с именем notes
find ~ -type f -name "*.md"	только файлы (f — file) .md
find /var/log -size +100k	файлы больше 100 КБ
- примеры, которые я использовал: 
find ~ -name "*.md" у себя в корне искал все файлы с расширением .md, но нужно было точнее указать корень 
find /etc -name "*.conf" тут нашёл все файлы с расширением .conf
find /var/log -size +100k нашёл все файлы весом более 100Kb в папке log и во всех подпапках
