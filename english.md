## Занятие 1. Язык ошибок и статусов

### Правило: окончание -ed
Означает прошедшее время или состояние:
- fail (падать) → **failed** (упал)
- load (загружать) → **loaded** (загружен)
- deny (отказывать) → **denied** (отказано)
- enable (включать) → **enabled** (включено)

### Чтение: man journalctl, раздел DESCRIPTION
Новые слова:
| Слово | Перевод |
|---|---|
| entries | записи (журнала) |
| accessible | доступный |
| calling user | пользователь, который запустил команду |
| oldest entry | самая старая запись |

Пересказ:
journalctl показывает содержимое журнала, который ведёт служба systemd-journald. Без параметров он выводит весь журнал, доступный текущему пользователю, начиная с самой старой записи. Поэтому важно, в каких группах состоит пользователь: я вижу системный журнал без sudo, потому что состою в группе adm.

I created a systemd service called heartbeat.
It runs as a dynamic user and writes a message every ten seconds.
If the process crashes, systemd restarts it automatically.
