## git status не видит изменения
- Ошибка: после правки файла git status пишет, что изменений нет
- Когда: Модуль 0, создание конспектов
- Причина: файл не сохранён в VS Code (белая точка ● на вкладке)
- Решение: Ctrl+S, затем снова git status

## Permission denied при ls /root
- Ошибка: `ls: cannot open directory '/root': Permission denied`
- Когда: Занятие 1, задание 5
- Причина: /root — папка администратора, права drwx------ (доступ только у root)
- Решение: `sudo ls -la /root` — выполнить одну команду с правами root

## No such file or directory: /ETC
- Ошибка: `bash: cd: /ETC: No such file or directory`
- Когда: Занятие 1, задание 7
- Причина: в Linux важен регистр букв, /ETC и /etc — разные пути
- Решение: `cd /etc`; использовать Tab для автодополнения

## No such file or directory: /procmeminfo
- Ошибка: `ls: cannot access '/procmeminfo': No such file or directory`
- Когда: Занятие 1, мини-практика /proc
- Причина: опечатка — пропущен `/` между proc и meminfo
- Решение: `ls -l /proc/meminfo`; набирать путь через Tab

## Не ошибка: сообщения snapd при apt upgrade
- Сообщение: `snapd.failure.service is a disabled or a static unit not running, not starting it`
- Когда: Модуль 0, обновление системы
- Причина: apt сообщает, что служба выключена и перезапускать её не нужно
- Вывод: настоящие ошибки содержат `E:`, `Error`, `Failed`; информационные сообщения — нет

## Permission denied (publickey) при git push
- Ошибка: 3 раза "Enter passphrase", затем `Permission denied (publickey)`
- Когда: Занятие 1, финальный коммит
- Причина: выключен NumLock — цифры пароля с цифрового блока не вводились
- Решение: включить NumLock, выполнить git push отдельной командой
- Вывод: при вводе невидимых паролей проверять NumLock, Caps Lock и раскладку; команды с запросом ввода выполнять по одной

## cp: -r not specified; omitting directory — копирование папки без -r
- Ошибка: копирование папки с файлами без -r
- Когда: Занятие 2
- Причина: не указал -r во время копирования папки
- Решение: при копировании папки с файлами нужно добавлять -r

## Удаление папки
- Ошибка: rmdir: failed to remove: Directory not empty — rmdir удаляет только пустые папки;
- Когда: Занятие 2, во время удаления папки с файлом внутри
- Причина: удаление командой rmdir - которая удаляет только пустые папки
- Решение: использовать командку rm -r 

## Мусор в репозитории
- Когда: Занятие 2, начало
- Причина: запустил шаблоны команд из объяснения (папка, файл) как есть, находясь в ~/devops-learning
- Решение: удалил лишнее, проверил ls -la и git status (пустые папки git status не показывает!)
- Вывод: сначала pwd, потом действие; слова-заполнители в примерах нужно заменять

## find: invalid -size type `K'
- Когда: Занятие 2, поиск больших файлов
- Причина: в find килобайты пишутся маленькой `k`, а мегабайты и гигабайты — большими `M`, `G`
- Решение: `find /var/log -size +100k`

## Permission denied при find /etc
- Ошибка: `find: '/etc/ssl/private': Permission denied`
- Когда: Занятие 2, поиск *.conf
- Причина: папки закрыты для обычного пользователя (в /etc/ssl/private — приватные ключи SSL)
- Решение: это не авария, find продолжает поиск; если нужно искать и там — `sudo find`

## Слишком много результатов в find ~
- Ошибка: искал свои .md, получил больше сотни чужих файлов
- Когда: Занятие 2, поиск .md в домашней папке
- Причина: find заходит в скрытые папки (`.vscode-server`)
- Решение: указать точнее — `find ~/devops-learning -name "*.md"`
