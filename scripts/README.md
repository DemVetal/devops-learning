# Скрипты

| Скрипт | Что делает | Запуск |
|---|---|---|
| `sysinfo.sh` | краткая сводка о системе: дата, пользователь, память, диск, время работы | `./sysinfo.sh` |
| `check_path.sh` |  определяет, что находится по указанному пути | `./check_path.sh <путь>` |
| `backup.sh` | делает архивные копии указанных папок с датой в имени | `./backup.sh` |
| `log_report.sh` |  выводит ежедневный отчёт по логу сайта | `./log_report.sh` |
| `heartbeat.sh` | учебная служба: раз в 10 секунд сообщает, что жива | `Запускается через systemd (heartbeat.service)` |
